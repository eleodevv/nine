Hecho para el flujo diario.

Tiempo real

La terminal y el móvil se actualizan solos por eventos en vivo cuando un puerto aparece o desaparece.

GET /eventos · ≤1 s

QR y código

Código de 6 dígitos con 2:00 de vida, un solo uso y QR escaneable desde la terminal.

POST /emparejar · 401 si expiró

Privilegios

Eleva con el diálogo nativo del sistema y controla también los puertos de root.

pkexec · osascript · UAC

Parar procesos

Termina el proceso de un puerto con confirmación, desde la terminal o el móvil.

confirmación · animación de salida

Lanzar servidores

Levanta Python o Node en el puerto que elijas, directo desde la app.

POST /lanzar · python · node

Binarios

Linux, macOS Intel y Apple Silicon, y Windows. Un solo archivo, sin dependencias.

Go 1.27 · ~8 MB

Instalación remota.

Un comando. Detecta tu sistema y descarga el binario. Sin .deb, sin gestores.

curl -fsSL https://raw.githubusercontent.com/eleodevv/nine/main/install.sh | bash

Detectando tu sistema…

  • --system instala en /usr/local/bin
  • --build compila desde el código con Go
  • --prefix=DIR elige el destino
